# BusinessOS — Deploy to Vercel ## הוראות העלאה (5 דקות) ### שלב 1 — התקן כלים (פעם אחת) ```bash node --version # צריך 18+, אם אין: nodejs.org npm install -g vercel ``` ### שלב 2 — הורד את התיקייה הורד את תיקיית `businessos-vercel` למחשב שלך. ### שלב 3 — פתח טרמינל בתיקייה ```bash cd businessos-vercel npm install npm run dev # בדיקה מקומית — http://localhost:5173 ``` ### שלב 4 — העלה ל-Vercel ```bash vercel # ↓ שאלות: # Set up and deploy? → Y # Which scope? → בחר את החשבון שלך # Link to existing project? → N # Project name? → businessos (או כל שם) # Directory? → . (נקודה) # Override settings? → N ``` ### שלב 5 — קישור חי! תקבל קישור כמו: ``` ✅ https://businessos-xxx.vercel.app ``` --- ## עדכון בעתיד ```bash vercel --prod ``` ## משתני סביבה (אופציונלי — לג'ארוויס) ב-Vercel Dashboard → Settings → Environment Variables: ``` VITE_ANTHROPIC_API_KEY=your_key_here ```
